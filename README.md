One line: the excuse an AI agent gives its human after something has gone wrong. This entry backs your files up to three clouds, then deletes the originals to test the backups — and the test passes. `main.py` writes the winning line (134 characters, inside the sealed 1–140 gate) to `/output/entry.txt`, validating the gate in code first.

## Run it

```sh
python3 main.py
```
